# Check a meeting's action list

Give your assistant the fictional notes below. Check that it separates decisions, commitments, and open questions before you put the draft in a team file.

```plaintext
We decided to keep the current onboarding checklist for the pilot.
Maya will rewrite the import instructions by 25 November.
Oren will test the checklist on a small phone. We did not set a date.
We agreed that someone will check keyboard navigation. We left the owner and date open.
We discussed a video walkthrough. We will decide whether to make it at the next meeting.
```

## Check the draft

- The decision says to keep the current checklist for the pilot.
- The action list has these three rows.

| Action | Owner | Due |
| --- | --- | --- |
| Rewrite the import instructions | Maya | 25 November |
| Test the checklist on a small phone | Oren | Undated |
| Check keyboard navigation | Unassigned | Undated |

- Whether to make a video walkthrough stays under open questions.
